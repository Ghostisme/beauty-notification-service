# 企微外部客户群发送方案

需求确认与官方文档核对日期：2026-10-12。

本工具的接收目标是包含外部联系人的企微外部客户群。门店负责人可以使用微信或其他企业的企微账号入群，不要求成为发送企业的内部员工。每家门店绑定其现有外部客户群，测试群为 `壹心-湖南-测试消息店`。

## 当前发送流程

1. 后台取得抖音订单、客资线索和授权解密结果，生成新订单、新留资或启用的状态变化通知。
2. 根据商户账号和门店 ID 查找对应门店的外部客户群绑定。
3. 已登录企业微信且已加入目标外部客户群的发送账号，在 Windows / Mac 客户端中发送通知。后台按群分派任务，发送端核对完整群名并执行发送。
4. 后台记录发送尝试、客户端确认结果和需要人工核实的情况。

阿里云服务器承担数据同步、解密、路由、任务队列与监控后台。Windows / Mac 电脑承担企业微信客户端操作，需要保持登录、桌面未锁定、窗口及校准可用。当前桌面回执表示在目标群客户端窗口识别到业务消息，不能等同于腾讯服务端的送达凭证。

Mac 使用系统 Vision 文字识别，需允许辅助功能与屏幕录制，原生 Apple 芯片安装步骤见 [操作手册](操作手册.md)。Mac 真实外部群发送仍需在实机验收。

## 官方接口能做到什么

| 能力 | 外部客户群适用情况 | 对本需求的影响 |
| --- | --- | --- |
| 自建应用的群聊消息 `appchat/send` | 官方限定为应用通过接口创建的内部群聊，不支持添加外部联系人 | 不能用于给现有外部客户群发送订单通知 |
| 客户联系“创建企业群发” | 支持客户群，可指定客户群 ID，但先创建任务，再由成员确认发送，并受客户群群发接收额度限制 | 可以用于成员确认的群发，不能据此实现每笔订单无人值守自动发送 |
| 第三方／服务商应用的客户群群发 | 需要相应授权，仍使用客户联系群发规则 | 应用类型不会自动改变成员确认和群发额度要求 |
| 已入群企微账号的 Windows / Mac 客户端发送 | 使用账号在目标外部客户群内的正常聊天能力 | 当前程序已实现的逐条自动发送方式，依赖可交互桌面 |

后台的“已有外部群发送工具的 HTTP 接口”是适配已有工具的入口。填写 HTTP 地址不代表已获得官方外部客户群无人值守发送能力，也不能证明该工具不依赖 Windows。采用其他工具前，需要用目标外部客户群验证实际投递、运行依赖、群匹配方式和发送结果。

## 后台如何配置

- 在“企业与门店”填写目标外部客户群的完整且唯一群名，发送账号需已加入该群。
- 使用桌面模式时，保留本工具生成的群标识。该标识用于队列分派，客户端通过完整群名定位；它不是从企业微信官方接口获取的客户群 `chat_id`。
- 在“接入设置 → 企微外部客户群发送”选择“Windows 企微客户端（外部客户群）”，再按 [Windows 发送端](Windows发送端.md) 配置连接和校准。
- 继续使用专用测试群验证。当前自动发送开关保持关闭，本次需求澄清和文案调整没有发送群消息。

## 官方依据

- [应用发送消息到群聊会话：概述](https://developer.work.weixin.qq.com/document/path/90244)：限定接口创建的内部群聊，不支持添加企业外部联系人。
- [应用推送消息](https://developer.work.weixin.qq.com/document/path/90248)：限定自建应用，目标群必须由该应用创建。
- [创建企业群发](https://developer.work.weixin.qq.com/document/path/92135)：支持客户群，但需要成员确认发送，并规定群发接收额度；第三方应用也需遵守此流程。
