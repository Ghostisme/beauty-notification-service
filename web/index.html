🔗 群绑定（群被改名了就来这里）

队列里的群名是入队那一刻写死的。群一旦被改名（通常是企微群主在手机上改的），存量消息就会一直发不出去，中继会报「找不到群」。
改商户卡里的「微信接收群名称」并保存 → 队列里还指着旧群名的消息会自动改指到新群，已 failed 的还会被重置为待发、由中继重发。下面这张表用来查有没有漏网的。

🧪 链路测试（发到测试群，不碰门店群）

往测试群塞一条测试消息，用来验证「服务器队列 → 微信号中继 → 微信群 → 回报」整条链路是否通。 它不拉订单、不占用任何门店群，并且会带上时间戳，所以可以反复点。
前提：中继用的那个微信号已经在测试群里（把几个关键号都拉进去，谁都能帮着看）。
发完等中继下一轮（默认 60 秒），到群里看一眼就知道了。

📤 待发队列（零备案通道）

服务器只负责入队；在你自己的 Windows 电脑上运行中继脚本，用普通微信号把消息发到指定群 — 不需要企业认证、可信域名、可信IP、ICP 备案。
pip install wxauto requests  然后  python wx_relay.py --server https://notification.hongquanquan.cn --token 你的令牌
注意：客户端自动化属于个人微信规范外操作，建议用小号并控制发送频率。
